# 東北沿岸の低視程(視程<1km)と 気温・海面水温・露点温度

沿岸10官署の毎時の気温・露点温度・相対湿度・視程と、近い海域の海面水温(日別)から、
視程<1km(低視程。霧とは限らない)の出やすさと、気温・海面水温・露点温度の関係を調べます。

```
pip install numpy pandas matplotlib
python fog_plot.py                   # 湿度 × (気温−海面水温) の階級ごとの視程<1km (1982年から。視程の記録は1989年から)
```

## Python ファイル(すべて同じフォルダに置く。`fog_plot.py` が読み込み処理を持つ)

| ファイル | 何を表すか | 主なオプション |
|---|---|---|
| `fog_plot.py` | 相対湿度 × (気温−海面水温) の階級ごとの、視程<1kmの出現率 (官署別) | `--each` 官署ごとに1枚、`--from-year`、`--hourly-only`、`--stations`、`--save-dir` |
| `fog_plot_temp_sst.py` | 気温(または露点温度)(横)×海面水温(縦) を1℃ごとに区切った、視程<1kmの出現率 | `--x ta`(気温)/`td`(露点温度)、`--each`、`--from-year`、`--hourly-only` |
| `fog_plot_ta_sst_period.py` | 上の図(気温×海面水温)を年代ごとに並べる。マス内に 視程<1kmだった時間 / 該当した時間 の数字つき | `--periods 1989 2000 2010 2020`、`--stations` |
| `fog_plot_year.py` | 夏季(6〜8月)の年平均の折れ線 (傾きつき) | `--what temps`(気温・海面水温・露点温度)/`dt`(気温−海面水温)/`gap`(露点温度−海面水温) |
| `fog_plot_vis_rate.py` | 夏季の視程<1kmの割合(%)の年ごとの推移。官署ごとに、全期間を通じて観測のある時刻だけを使い、観測が毎時になる前後を公平に比べる。視程が毎時になった年に▲ | `--from-year`、`--save-dir` |
| `fog_plot_sst_fog.py` | 夏季の海面水温の平均(横)と公式の霧日数(縦)の散布図 (1点=1年、官署別)。最新の均質区間を濃く、2023年を赤で示し、相関係数を題に書く。`東北地方気象官署月別値霧日数.csv` が必要 | `--highlight`、`--kiri`、`--save-dir` |
| `fog_days.py` | 公式の霧日数(棒)に、条件を満たす日数や年平均(折れ線)を重ねる (官署別) | モード `rh` `cond` `temps` `gap` `chart` (下記) |
| `fog_chart.py` | `fog_days.py chart` の描画 (5年移動平均・回帰直線・欠測・三沢など)。単独では動かない | — |

`fog_days.py` のモード (`python fog_days.py 〔モード〕 〔オプション〕`、省略すると `rh`。`fog_days.py chart --help` などで各モードのオプションが出る):

| モード | 重ねるもの |
|---|---|
| `rh` | 相対湿度 と 気温−海面水温 の条件を満たす日数 (黒線) と、先生の条件 (灰色の破線) |
| `cond` | 海面水温−露点温度 ≦0℃ の時刻がある日の日数。`--gap-max` `--gap-min` `--min-hours`、`--sat-max`(気温−露点温度の上限)、`--dt-min` `--dt-max`(気温−海面水温の範囲) で条件を変える |
| `temps` | 気温・海面水温・露点温度の年平均 (折れ線、右の軸) |
| `gap` | 海面水温−露点温度の年平均 (折れ線、右の軸。上ほど小さい向きに反転) |
| `chart` | Colab のノートブックと同じ図 (官署ごとに1枚の画像を `out/` に保存)。5年移動平均、区間ごとの回帰直線と傾き、▲、欠測、八戸には三沢の線。条件は `--cond rh`(湿度 `--rh-min` と気温差 `--dt-abs`)、`--cond td`(`--gap-max` `--sat-max` `--dt-min` `--dt-max`)、`--cond none`。`--temps` を付けると、夏季の気温・海面水温・露点温度の年平均を、右の軸に折れ線で重ねる (どの `--cond` とも同時に使える) |

`fog_days.py` は、官署を3つずつの図に分けて、複数のウィンドウに表示します (`--per-fig 2` などで数を変える)。
どのファイルも `python ファイル名 --help` でオプションの説明が出ます。

## Colab 用ノートブック

`fog_days.py chart` は、v5 のノートブックと同じ図を Python だけで出します (Google Drive へのアップロードは不要)。

- `fog_days_claude_v5.ipynb`: 時別値から、湿度と気温−海面水温の条件を満たす日数を、スライダーで変えながら霧日数に重ねる。
- `fog_days_claude_climate.ipynb`: 霧日数のグラフ (`夏季の霧日数(東北地方claude_v5).ipynb` と同じ形式、1セル) に、夏季の気温(赤)・海面水温(青)・露点温度(濃い緑)の年平均を右の軸の折れ線で追加したもの。5年移動平均は黒、トレンドは橙。`SHOW_CLIMATE = False` で折れ線を消せる。
- `fog_days_claude_td.ipynb`: v5 と同じ形式で、露点温度を使った条件 (海面水温−露点温度、必要なら気温−露点温度・気温−海面水温) を、プルダウンやスライダーで変える。
- `fog_days_claude_daily.ipynb`: 日別値 (`東北地方沿岸気象官署日別値/`) で同じことをする。

## データ(Python ファイルと同じフォルダ)

- `東北沿岸域の海面水温/*.txt`: 海面水温 (気象庁 日別値、12海域)
- `東北地方沿岸気象官署時別値/*.csv`: 気象庁 時別値、年ごと、6/1〜8/31。官署ごとに 気温、露点温度、相対湿度、視程 の順 (露点温度は1984年から)
- `東北地方気象官署月別値霧日数.csv`: 霧日数 (気象庁 月別値)。`fog_days.py` で使う
- `三沢月別値霧日数.csv`: 三沢の霧日数 (METAR、METAR+SPECIAL の月別値)。`fog_days.py chart` が八戸の図に重ねる (無ければ描かない)

## 図の見方と注意

- 色=視程<1kmの出現率(%) (全官署で同じ基準)。マス内の数字は 上=視程<1kmだった回数 / 下=該当した回数。灰色=視程<1kmが0回、または該当した回数が40回未満 (`MIN_N`)、空白=該当なし。
- 横軸・縦軸の目盛りはマスの境目 (例: 気温16と17の間のマスは 16.0℃以上17.0℃未満)。
- 相対湿度は 80%未満、80〜85、85〜90、90〜95、95%以上 (100%を含む。湿度計の誤差が5%程度のため) の5階級。
- 官署と海域の対応は `STATION_SST` (図は酒田から小名浜まで、日本海側→太平洋側の順)、視程の基準は `FOG_KM`。
- 視程が毎時になった年は官署ごとに違い (むつ1998、石巻2003、深浦2005、大船渡2007、八戸・宮古2008、小名浜2009、酒田2010、秋田・青森2020。気象庁「気象観測統計指針」表3.4－6の、観測の自動化 (目視から視程計) の日付から決めている。`fog_plot.py` の `AUTOMATION`)、
  それ以前は間引かれています (観測時刻が偏る)。
- 相対湿度100%の記録は、2013年ごろまでほとんど無く (センサーなどの変更の可能性。1998年ごろと2006年ごろにも増減がある)、時別値の均質番号はすべて1で変更は示されていない。湿度や、湿度から求める露点温度を使う条件は、それ以前と比べられません。
- 1989年以前の気温・露点温度の観測は3時間おきです。
