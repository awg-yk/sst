# 東北沿岸の低視程(視程<1km)と 気温−海面水温・相対湿度

沿岸10官署の毎時の気温・相対湿度・視程と、近い海域の海面水温(日別)から、
視程<1km(低視程。霧とは限らない)の出現率を 相対湿度 × (気温−海面水温) で調べます。

```
pip install numpy pandas matplotlib
python fog_plot.py                   # 全期間
python fog_plot.py --from-year 2020  # 視程が毎時になった2020年以降だけ
python fog_plot.py --metric lift     # 色にする指標を変える (share / lift / rate)
```

- `fog_plot.py` 1ファイルで動きます。ファイルには保存せず、官署別の図を画面に表示します。
- データ(`fog_plot.py` と同じフォルダ):
  - 海面水温 `*.txt`(気象庁 日別値、12海域)
  - `東北地方沿岸気象官署時別値/*.csv`(気象庁 時別値、年ごと、6/1〜8/31)
- マス内の数字は 上=視程<1kmだった回数 / 下=該当した回数。
- 色にする指標 `--metric`:
  - `share`(既定): 視程<1kmだった時刻のうち、そのマスに入っていた割合(各官署で合計100%)。分母が少ないマスは自然に小さくなる。
  - `lift`: 相対リスク = そのマスの出現率 ÷ その官署全体の出現率(1=平均、赤=平均より高い、青=低い)。
  - `rate`: 出現率 = 該当した時刻のうち視程<1kmだった割合。該当回数が50回未満は薄く、少なすぎる(15回未満)と灰色。
- 相対湿度は 90%未満(1階級)と、90〜100%の1%ごと。
- 官署と海域の対応は `STATION_SST`、視程の基準は `FOG_KM`。
- 視程は2020年から毎時で、それ以前は間引かれています(観測時刻が偏る)。
