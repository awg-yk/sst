# 東北沿岸の低視程(視程<1km)と 気温−海面水温・相対湿度

沿岸10官署の毎時の気温・相対湿度・視程と、近い海域の海面水温(日別)から、
視程<1km(低視程。霧とは限らない)だった回数を、相対湿度 × (気温−海面水温) の階級ごとに調べます。

```
pip install numpy pandas matplotlib
python fog_plot.py                   # 官署ごとに、視程が毎時になった年以降だけ (既定)
python fog_plot.py --from-year 2014  # さらに、この年以降だけに絞る
python fog_plot.py --all-years       # 視程が間引かれていた古い年も含める
```

- `fog_plot.py` 1ファイルで動きます。ファイルには保存せず、官署別の図を画面に表示します。
- データ(`fog_plot.py` と同じフォルダ):
  - 海面水温 `*.txt`(気象庁 日別値、12海域)
  - `東北地方沿岸気象官署時別値/*.csv`(気象庁 時別値、年ごと、6/1〜8/31)
- 図の見方: 色=視程<1kmだった回数(全官署で同じ基準)。マス内の数字は 上=視程<1kmだった回数 / 下=該当した回数。
  灰色=該当した時刻はあるが視程<1kmは0回、空白=該当した時刻が無い。
- 相対湿度は 90%未満(1階級)と、90〜100%の1%ごと。気温−海面水温は −6〜6℃ を中心に階級分け。
- 官署と海域の対応は `STATION_SST`、視程の基準は `FOG_KM`。
- 視程が毎時になった年は官署ごとに違い(むつ1998、石巻2003、深浦2005、大船渡2007、八戸・宮古2008、小名浜2009、酒田2010、秋田・青森2020)、
  それ以前は間引かれています(観測時刻が偏る)。既定ではこの年以降だけを使い、図の題に開始年を表示します。
- 注意: 相対湿度100%の記録は、2013年ごろまでほとんど無く(センサーなどの変更の可能性)、それ以前は湿度の階級が他の年と比べられません。
